# R3 — Random 1-Shot vs Nearest 1-Shot Benchmark

## 1. Objective

Implement and execute a controlled experiment to determine whether the accuracy improvement observed with Nearest 1-shot retrieval comes from:

1. Providing an in-context example (the general 1-shot effect).
2. Selecting a semantically relevant example using nearest-neighbor retrieval (the retrieval-selection effect).

The experiment must isolate these effects without changing the underlying inference model, evaluation dataset, prompt format, or scoring procedure.

**This is an implementation and experimental execution task, not merely a planning task.**

Inspect the existing benchmark repository, implement the necessary evaluation code, run the experiments, and produce a reproducible report.

## 2. Background

The existing benchmark includes:

- S1: Zero-shot inference.
- R1: Nearest 1-shot retrieval.
- R2: Similarity-gated Nearest 1-shot.

The previous held-out evaluation reported:

| Strategy | Accuracy |
|---|---:|
| S1 — Zero-shot | 44.69% |
| R1 — Nearest 1-shot | 55.05% |
| R2 — Similarity-gated 1-shot | 55.19% |

The R1 improvement over S1 was +10.36 percentage points.

However, this result does not establish whether nearest-neighbor selection is more effective than simply providing an arbitrary training example.

R3 addresses this question.

## 3. Experimental Strategies

Do not introduce similarity thresholds, fallback gates, or additional examples into the primary R3 experiment.

## 6. Random Exemplar Selection

Implement a deterministic random selection mechanism.

### Primary sampling policy

For each evaluation query:

1. Construct the eligible exemplar pool.
2. Exclude the evaluation query itself if present.
3. Apply the same eligibility and leakage restrictions used by R1.
4. Select one example uniformly at random.
5. Format the selected example exactly as R1 formats its retrieved example.
6. Execute inference with the resulting prompt.

### Important fairness constraint

The primary random baseline must sample from the same candidate population available to the nearest-neighbor retriever.

Do not select examples from a broader or narrower dataset without explicitly reporting the difference.

If the R1 retrieval system uses a restricted pool, reproduce those restrictions.

If eligibility depends on task type, group membership, context length, or data availability, preserve those constraints.

Do not automatically restrict random selection to examples sharing the same label or correct answer.

### Context-length handling

Ensure every selected example fits within the configured 4096-token context window under the same prompt-construction policy used by R1.

Do not truncate only the R3 examples using a different algorithm.

If the existing R1 system uses context-length eligibility filtering, reuse it.

Report queries for which no eligible random example exists.


### Primary comparisons

**General 1-shot effect:**

```text

```

This estimates the benefit of adding an example without similarity-based selection.

**Nearest-neighbor selection effect:**

```text

```

This estimates the additional benefit of selecting a nearest-neighbor example instead of a random eligible example.

**Total retrieval-augmented improvement:**

```text

```

## 10. Statistical Analysis

Use paired comparisons.

All strategies must be evaluated on the same held-out queries.

### Required analysis

1. Calculate paired accuracy differences.
2. Use group-cluster bootstrap confidence intervals.
3. Preserve the original evaluation grouping.
4. Compute a 95% confidence interval for R1 versus R3.
5. Report per-seed paired differences.
6. Include between-seed variation.
7. Avoid treating repeated predictions of the same query as independent observations.

For R1 versus mean R3, use a cluster bootstrap over evaluation groups while retaining all predefined R3 seeds for each sampled group.

Also report the R1 minus R3 difference separately for every seed.

Do not claim statistical significance using an independence assumption that ignores repeated queries or scenario families.

### Interpretation

Classify the result as:

- Evidence favoring Nearest 1-shot.
- No clear difference.
- Evidence favoring Random 1-shot.

Base the conclusion on the observed difference, uncertainty interval, and consistency across seeds.

Do not equate a nonsignificant difference with proof of equivalence.
